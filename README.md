<h1 align="center">Certificate Store Viewer</h1>

<p align="center">
  <b>Browse, view, and export certificates from Windows certificate stores.</b>
</p>

---

## What This Tool Does

- Browse all Windows certificate stores (Personal, Root, CA, Trusted Publishers)
- View detailed certificate info - issuer, expiry, thumbprint, subject, serial number
- Export certificates to multiple formats: DER, PEM, PKCS#12
- Search and filter certificates
- Certificate Trust List (CTL) viewer
- Works on Windows 10 and 11
